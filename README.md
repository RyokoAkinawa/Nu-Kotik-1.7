# Ну Котик 1.7

2D-шутер про котика: отбивайся от волн злых дядь, покупай оружие и улучшения в лавках, выбирай карточки между волнами. Каждая пятая волна — босс. Можно играть вдвоём по сети.

**Игра сделана с помощью ИИ.**

Версия 0.1.7.

## Играть в браузере

**[https://ryokoakinawa.github.io/Nu-Kotik-1.7/](https://ryokoakinawa.github.io/Nu-Kotik-1.7/)**

Ставить ничего не нужно: вся игра — один файл `index.html`. Подойдёт браузер не старше 2021 года.

На телефоне и планшете сенсорное управление включается само. Держи телефон горизонтально. Если в правом верхнем углу меню есть кнопка «на весь экран», нажми её.

## Android

**[Скачать nu-kotik-2.apk](https://ryokoakinawa.github.io/Nu-Kotik-1.7/nu-kotik-2.apk)** — 2,5 МБ, Android 7.0 и новее.

1. Открой эту страницу на телефоне и нажми ссылку: файл скачается.
2. Открой скачанный файл. Android спросит, можно ли ставить приложения из этого источника (из браузера или из «Файлов»). Разреши.
3. Нажми «Установить». Приложения нет в Google Play, поэтому телефон может показать предупреждение о неизвестном разработчике.

Приложение — та же игра, но сразу на весь экран и без браузера. Доступ к сети нужен только для игры вдвоём, других разрешений приложение не просит. Кнопка «Назад» ставит паузу или закрывает лавку, два нажатия подряд — выход.

## Управление

| Действие | Компьютер | Телефон |
|---|---|---|
| Бег | W A S D | левый стик |
| Прицел | мышь | правый стик |
| Огонь | левая кнопка мыши | ОГОНЬ |
| Рывок | Пробел или Shift | РЫВОК |
| Перезарядка | R | R |
| Сменить ствол | Q, E или 1–8 | СТВОЛ |
| Говорить, нанять, ворота | F | F |
| Скрыть или показать HUD | U | HUD |
| Пауза | Esc | II |

Ещё клавиши на компьютере: V — верхом на Токи, G — бензин, H — погладить друга.

## Игра вдвоём

Игроки соединяются напрямую и для этого обмениваются кодами: код показывает игра, переслать его другу можно в любом мессенджере. Создать игру можно и с телефона. Подключаться вторым игроком пока нужно с компьютера: у второго игрока нет сенсорного управления.
